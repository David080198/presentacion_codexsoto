MÓDULO 01 // FUNDAMENTOS

¿Qué es el PLN?

El Procesamiento de Lenguaje Natural es la rama de la Inteligencia Artificial que permite a las máquinas leer, entender, interpretar y generar lenguaje humano.

Combina lingüística computacional con machine learning y deep learning para convertir texto o voz en información estructurada que un programa puede usar.

TRES CAPACIDADES CLAVE

Entender — extraer significado e intención

Procesar — estructurar texto no estructurado

Generar — producir lenguaje natural y coherente

MÓDULO 02 // PREPROCESAMIENTO

Normalización y tokenización

NORMALIZACIÓN

Estandarizar el texto antes de procesarlo: minúsculas, acentos, espacios y caracteres especiales.

TOKENIZACIÓN

Dividir el texto en unidades mínimas (tokens): palabras, subpalabras o caracteres.

Palabra: "gatos" → un token

Subpalabra: "jugando" → "jug" + "ando"

Carácter: "PLN" → "P" + "L" + "N"

tokenizar.py

import nltk

texto = "¡El PLN es increíble!"

texto = texto.lower()

tokens = nltk.word_tokenize(texto)

print(tokens)

# ['¡el', 'pln', 'es', 'increíble', '!']

MÓDULO 02 // PREPROCESAMIENTO

Stopwords, stemming y lematización

Stopwords

Palabras muy frecuentes y de bajo valor semántico: "el", "la", "de", "que".

"el gato de la casa"

→ "gato casa"

Stemming

Corta la palabra a su raíz de forma mecánica, sin analizar gramática. Rápido pero tosco.

"corriendo", "corredor"

→ "corr"

Lematización

Reduce a la forma canónica usando gramática y diccionario. Más preciso que el stemming.

"corriendo", "corrió"

→ "correr"

MÓDULO 03 // REPRESENTACIÓN

Bag of Words y TF-IDF

BAG OF WORDS (BoW)

Conteo de palabras

Cada documento se representa como un vector con la frecuencia de cada palabra del vocabulario. Ignora el orden y el contexto.

"el gato ve al gato"

→ {"el":2, "gato":2, "ve":1, "al":1}

TF-IDF

Frecuencia ponderada

Pondera cada palabra por su frecuencia en el documento (TF) y penaliza las que aparecen en muchos documentos (IDF).

TF-IDF = TF(t,d) × log(N / DF(t))

Palabras como "el" o "de" obtienen un peso bajo; términos poco comunes pero relevantes, como "algoritmo", obtienen un peso alto.

MÓDULO 03 // REPRESENTACIÓN

Word embeddings

Los embeddings representan cada palabra como un vector denso donde palabras con significado similar quedan cerca en el espacio.

A diferencia de BoW y TF-IDF, capturan relaciones semánticas: Word2Vec y GloVe entrenan estos vectores a partir de grandes volúmenes de texto.

Clasificación de texto

MÓDULO 05 // TRANSFORMERS Y LLMS

El mecanismo de atención

El self-attention permite que cada palabra "mire" a todas las demás palabras de la oración y decida cuáles son relevantes para interpretarla.

Así, el modelo resuelve ambigüedades usando el contexto completo, no solo las palabras vecinas.

¿A QUÉ LE PRESTA ATENCIÓN "ESTABA"?

El animal no cruzó la calle porque estaba cansado

El modelo conecta "estaba" con "animal", no con "calle", gracias al contexto.

MÓDULO 05 // TRANSFORMERS Y LLMS

BERT, GPT y Hugging Face

BERT

Codificador bidireccional

Lee el contexto completo (izquierda y derecha) a la vez. Ideal para entender: clasificación, NER, búsqueda semántica.

GPT

Decodificador autorregresivo

Predice la siguiente palabra usando solo el contexto previo. Ideal para generar: texto, código, conversación.

from transformers import pipeline

clasificador = pipeline("sentiment-analysis")

resultado = clasificador("¡Este curso de PLN está increíble!")

MÓDULO 05 // TRANSFORMERS Y LLMS

Fine-tuning de modelos

El fine-tuning toma un modelo ya preentrenado en grandes volúmenes de texto y ajusta sus pesos con un dataset específico para una tarea concreta.

Es más rápido y requiere muchos menos datos que entrenar un modelo desde cero.

¿PROMPTING O FINE-TUNING?

Prompting / few-shot — rápido, sin entrenar, bueno para empezar.

Fine-tuning — cuando necesitas precisión, formato fijo o dominio muy específico.

1

Cargar un modelo base preentrenado

2

Preparar un dataset etiquetado de la tarea

3

Entrenar pocas épocas con learning rate bajo

4

Evaluar con métricas de la tarea

5

Desplegar el modelo ajustado
