Autoatención

Haz clic en cualquier palabra. Grosor del arco = peso de atención (valores ilustrativos).

El cálculo detrás de la atención

Query · Key · Value

Atención(Q,K,V) = softmax( Q·Kᵀ / √d ) · V

Q · Query

Lo que cada palabra busca. «¿Quién hace la acción?»

K · Key

La etiqueta que cada palabra ofrece. «Soy un sustantivo plural.»

V · Value

La información que entrega si la eligen.

Function / tool calling

El modelo pide, tu código ejecuta

1 · Describes la herramienta
{
  "name": "tipo_cambio",
  "description": "Tasa actual entre dos monedas",
  "parameters": {
    "origen":  {"type": "string"},
    "destino": {"type": "string"}
  }
}
2 · El modelo responde con una llamada
{ "tool": "tipo_cambio",
  "args": { "origen": "USD", "destino": "MXN" } }
3 · El bucle del agente (Python)
# un agente en ~12 líneas
mensajes = [{"role": "user", "content": pregunta}]

while True:
    resp = llm.chat(mensajes, tools=HERRAMIENTAS)

    if not resp.tool_calls:
        print(resp.content)       # respuesta final
        break

    for call in resp.tool_calls:
        resultado = ejecutar(call.name, call.args)
        mensajes.append({"role": "tool",
                         "content": resultado})

Model Context Protocol

MCP: el USB-C de los agentes

Antes

Una integración a la medida por cada herramienta y cada modelo. N × M conectores.

Con MCP

Un protocolo abierto: un servidor expone herramientas, datos y prompts; cualquier cliente compatible los usa.

Y entre agentes

Protocolos como A2A permiten que agentes de distintos proveedores se coordinen.
