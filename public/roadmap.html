Agentes de IA 2026

Tu roadmap para construir y dominar agentes en 6 meses

Este roadmap te guía desde los fundamentos de Python hasta la construcción de agentes LLM en producción. Se basa en el camino que recorrí en los últimos 4 años (MIBI, CodexSoto, investigación en CIC-IPN). Cada etapa incluye tecnologías, proyectos prácticos y certificaciones reales que aumentan tu valor en el mercado laboral.

Las 6 etapas

Mes 1

Fundamentos

Python sólido, estructuras de datos, APIs HTTP y bases de datos. La base de todo.

Tecnologías

Python 3.11+ Pandas SQL FastAPI PostgreSQL Git

Objetivo: Desarrollar una API REST que consulte una base de datos.

Mes 2

Machine Learning

Limpieza de datos, extracción de características, modelos de sklearn. ML clásico antes de los LLMs.

Tecnologías

Scikit-learn NLTK SpaCy Matplotlib Jupyter

Objetivo: Entrenar un clasificador binario con un dataset curado.

Mes 2–3

NLP y Transformers

Desde tokenización hasta modelos pre-entrenados. Los Transformers son el centro de todo hoy.

Tecnologías

Transformers (HF) PyTorch BERT / RoBERTa Fine-tuning LoRA

Objetivo: Fine-tunear un modelo de clasificación con tus datos.

Mes 3–4

LLMs locales y en nube

Ollama, Llama 3, GPT via API, prompt engineering. Haz un agente antes de los agentes.

Tecnologías

Ollama Llama 3 / Mistral OpenAI API Prompt Engineering LangChain

Objetivo: Construye un RAG: carga tus PDFs y consulta con el LLM.

Mes 4–5

Agentes y herramientas

Tool calling, bucle de razonamiento, ReAct. Un LLM que ejecuta código y consulta APIs.

Tecnologías

LangGraph Tool calling APIs externas n8n MCP

Objetivo: Un agente que responda preguntas sobre tu base de datos y APIs.

Mes 5–6

Producción y escala

Docker, CI/CD, monitoreo de tokens y costo, seguridad y observabilidad.

Tecnologías

Docker Compose GitHub Actions Logging y monitoreo AWS / Azure Evaluaciones

Objetivo: Despliega tu agente en una VPS o nube con observabilidad.

Certificaciones que transforman tu CV

AWS (Amazon Web Services)

AWS Certified Cloud Practitioner

Duración: 2–4 semanas

Costo: $99 USD examen

Nivel básico. Entiende EC2, S3, RDS, Lambda. Ideal para comenzar. Muchos empleadores lo ven como "sabe qué es cloud".

Requisito previo para certificaciones AWS más avanzadas.

AWS Certified Solutions Architect Associate

Duración: 6–8 semanas

Costo: $150 USD examen

Diseña soluciones en AWS. VPC, IAM, auto-scaling. Muy demandado. Salario +15% típicamente.

Mejor ROI si trabajas con backend o DevOps.

AWS Certified Developer Associate

Duración: 4–6 semanas

Costo: $150 USD examen

Para los que coden en AWS. Lambda, DynamoDB, API Gateway. Si desarrollas agentes en la nube, tienes que conocer esto.

Complementa bien con la Architect.

AWS Certified Machine Learning Specialty

Duración: 8–12 semanas

Costo: $300 USD examen

SageMaker, entrenamiento de modelos en AWS. Si trabajas con LLMs y ML, esto te abre puertas.

Requiere experiencia; no es tu primer examen AWS.

Microsoft Azure

AZ-900: Azure Fundamentals

Duración: 1–2 semanas

Costo: $165 USD examen

Básico de Azure. Mínimo absoluto. Si trabajas en empresas con stack Microsoft, tienes que tenerlo.

Gratuito si eres estudiante (GitHub Education).

AZ-104: Azure Administrator Associate

Duración: 6–8 semanas

Costo: $165 USD examen

Administra recursos en Azure: VMs, redes, almacenamiento. Similar a la Solutions Architect de AWS.

Paso previo a roles más especializados.

AZ-204: Azure Developer Associate

Duración: 6–8 semanas

Costo: $165 USD examen

Desarrolla apps en Azure. Azure Functions, App Service, Cosmos DB. Para backend y APIs en Azure.

Azure tiene Azure OpenAI Service: perfecto para agentes.

AZ-700: Azure Network Engineer Associate

Duración: 4–6 semanas

Costo: $165 USD examen

Redes en Azure. VPN, firewall, CDN. Especializado. Si tu carrera es DevOps/infraestructura.

Menos demandado que Admin o Developer, pero muy específico.

Google Cloud Platform (GCP)

Google Cloud Associate Cloud Engineer

Duración: 6–8 semanas

Costo: $200 USD examen

Diseña, despliega y gestiona GCP. Compute Engine, App Engine, BigQuery. GCP es fuerte en ML y datos.

Si trabajas con data science o ML, GCP es excelente.

Google Cloud Professional Data Engineer

Duración: 8–12 semanas

Costo: $200 USD examen

BigQuery, Dataflow, ML. Si trabajas con datos masivos y necesitas entrenar modelos a escala.

Muy especializado. Para Data Science roles con agentes.

Metodologías Ágiles · Certificaciones

Certified Scrum Developer® (CSD®)

Duración: 2 días presencial o 4–6 semanas en línea

Costo: $400–600 USD curso + $200 USD examen

Importancia: MUY ALTA. Yo lo tengo (CSD®). Demuestra que sabes trabajar en equipos, sprints y que entiendes XP.

CertiProf · Válida de por vida · Reconocida globalmente.

Certified Scrum Product Owner® (CSPO®)

Duración: 2 días presencial o 4–6 semanas en línea

Costo: $400–600 USD curso + $200 USD examen

Si quieres liderazgo o Product Manager. Entiende roadmap, backlog, stakeholders. Complementa el CSD.

Juntos (CSD + CSPO) demuestras visión 360 del desarrollo.

Certified Scrum Master® (CSM®)

Duración: 2 días presencial

Costo: $400–600 USD curso + $200 USD examen

Facilita el team. Menos técnico que CSD. Si quieres ser Scrum Master, sí. Si eres developer, CSD es mejor.

CertiProf · El CSM es un rol, no una habilidad de desarrollo.

Scaled Agile Framework (SAFe) Certification

Duración: 1–2 días

Costo: $500–800 USD según nivel (Practitioner, Technical, Leader)

Para grandes empresas con múltiples equipos. Si trabajas en tech corporativo, vale la pena. Menos en startups.

Niveles: Practitioner → Technical Practitioner → Leader.

Kanban System Design (KMP I)

Duración: 4–6 semanas

Costo: $400–500 USD

Alternativa a Scrum. Mejor para equipos con trabajo en flujo continuo (MLOps, DevOps, Infraestructura). Visualiza bottlenecks.

Less prescriptivo que Scrum. Gana tracción en proyectos ágiles.

Impacto de los agentes en la industria (2026)

Los agentes no son futurismos. Hoy (2026), empresas reales usan agentes para:

Finanzas. CFO virtual que analiza ingresos y emite recomendaciones.
Manufactura. Inspección visual automática y mantenimiento predictivo.
Retail. Predicción de ventas e insumos; punto de venta inteligente.
Soporte TI. Mesa de servicio que clasifica y resuelve tickets.
Investigación. Agentes que leen Papers y generan resúmenes citados.
Código. Agentes que editan repositorios, abren PRs, corren tests.
Legal. Revisión de contratos con fuente citada.
RH. Screening de CVs, programación de entrevistas.

¿Cuánto gana un developer con agentes?

Basándome en datos de mercado 2026 (México, LATAM, US remoto):

Junior full-stack (sin agentes): $25k–$35k USD/año
Senior full-stack + 1 certificación cloud (sin agentes): $60k–$80k USD/año
Senior full-stack + cloud + CSD + agentes en producción: $100k–$150k USD/año
ML Engineer + agentes + AWS ML Specialty: $120k–$160k USD/año

Por qué los agentes son tan importantes ahora (2026)

  • Escasez de talento. Pocos developers saben construir agentes. Demanda > Oferta.
  • ROI inmediato. Una empresa automatiza un proceso de 3 personas con un agente. Paga el desarrollo en 1–2 meses.
  • Competencia diferenciada. El que domina agentes cierra clientes que otros no pueden.
  • Multiherramienta. Los agentes atan LLMs, APIs, bases de datos y workflows. Es todo.
  • Modelos abiertos listos. Ollama + Llama 3 = agentes en tu laptop sin pagar a OpenAI.

Cómo empezar este mes

Semana 1

  • Instala Ollama. Corre `ollama pull mistral`.
  • Haz un script Python que llame al LLM local via API.
  • Lee el artículo de ReAct (Yao et al., 2022).

Semana 2

  • Construye tu primer RAG: carga un PDF, haz queries.
  • Usa Chroma (vectorial) o pgvector (Postgres).
  • Repositorio en GitHub con README claro.

Semana 3

  • Agrega herramientas: define 2–3 funciones.
  • LLM decide cuándo llamarlas (tool calling).
  • Implementa el bucle ReAct.

Semana 4

  • Despliega con Docker. Una API REST.
  • Documentación con Swagger.
  • Inicia tu solicitud de AWS Cloud Practitioner.
